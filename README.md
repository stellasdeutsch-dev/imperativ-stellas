# Imperativ за один вечер — Stellas Deutsch

Одностраничник-урок по немецкому повелительному наклонению (Imperativ, уровень A1)
в сторителлинг-стиле, плюс промо платформы Stellas A0–C1.

- Дизайн-система по мотивам инвест-лендинга с Behance (тёмно-синие карточки, синие
  градиентные пилюли, двухтональные заголовки)
- Mobile-first, без сборки и зависимостей — один `index.html`
- Реальные материалы: скриншоты платформы в Notion, скринкасты, отзывы из личных сообщений

## Интерактив и анимации

- Прогресс-бар чтения с кольцевым индикатором
- Конструктор Imperativ на 10 глаголах с пошаговой анимацией
- SVG-схема выбора формы (du / ihr / Sie) с прорисовкой связей
- FLIP-анимация отделяемой приставки: `aufmachen` → `Mach die Tür auf!`
- Шкала «температуры фразы»: приказ → bitte → Konjunktiv
- Тренажёр на 12 вопросов с разбором ошибок и кольцом результата
- Диаграммы: причины провала, сутки в смену, подписка против «навсегда», шкала A0–C1
- Уважает `prefers-reduced-motion`
